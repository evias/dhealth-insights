This repository implements a Web App that displays a Bulletin Board with
latest insights collected from many different Healthcare news outlets online
and summarized with dHealth Intelligence (AIDH Agent).

Users may upvote/downvote insights as they are posted.

⚠️ CAUTION: EXPERIMENTAL SOFTWARE

This is experimental software not intended for production use.
Use at your own risk. See LICENSE for the complete terms and liability limitations.

### Dependencies

- Node.js 22.23.4+
- npm or yarn

## Developer notes

```bash
# Clone and install
git clone https://github.com/evias/dhealth-insights
cd dhealth-insights/
npm install
```

### Start the Server

```bash
npm start
```

Server runs on `http://localhost:3000`
